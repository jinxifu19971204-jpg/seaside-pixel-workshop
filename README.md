# 海滨像素工坊

用于 GitHub Pages 的静态加密网页。请将本目录中的 `index.html`、`.nojekyll` 和本说明放在仓库根目录。

## 发布

在仓库 Settings → Pages 中，选择 Deploy from a branch，分支为 main，目录为 /(root)，然后保存。
如果仓库的默认分支不是 main，选择你实际上传文件的分支。
等 GitHub 完成发布后，使用 Pages 页面中显示的网址。根目录必须有 index.html。

访问密码由工具提供者单独告知，请不要写进本仓库、提交信息、Issue 或公开评论。
不要把原 RAR、原始 JS/CSS、之前的普通密码版 HTML 或含密码的使用说明上传到本仓库。

## 加密方式与边界

原工具的完整 HTML、CSS 和 JavaScript 使用 AES-256-GCM 加密，密钥由访问者输入的密码经 PBKDF2-SHA256 派生。
发布文件只包含随机盐、随机 IV、派生参数和密文，没有内嵌密码或未加密的工具代码。
解密使用浏览器 Web Crypto API，推荐使用新版 Edge/Chrome，通过 GitHub Pages 的 HTTPS 地址访问。
入口不持久化密码或解密密钥，也不把密码发送给服务器。原工具的作品仍按原有逻辑保存在当前浏览器。

这不是服务器登录、账号权限或防复制系统：知道密码的访问者可以保存解密后的内容；可下载密文进行离线猜密码；密码越随机、越长越好。
不要用于公司机密或要求严格权限控制的资料。GitHub Pages 不等于内部网络。
已下载的旧加密文件不会因你更新网站密码而自动失效，旧密码仍可以解密旧文件。
如需变更密码，必须重新加密原工具并发布新 index.html，不能只在公开文件中修改一行密码。
网页托管方及仓库写入者必须可信：被篡改的入口可能窃取访问者输入的密码。

原工具主体未改动；仅合并为自包含页面并加密，由新的入口在解密成功后载入。
